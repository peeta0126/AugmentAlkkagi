# 팀 작업 안내

누가 뭘 하는지는 디스코드가 아니라 **GitHub 이슈**에서 본다.

## 웹 화면으로 보기 (제일 쉬운 방법)

게임 폴더에서 `팀보드.bat`을 더블클릭하거나, 터미널에서 한 줄:

```bash
python .github/team/team.py web
```

브라우저에 작업판이 열린다. 내 컴퓨터에서만 열리고, 이미 로그인된 GitHub(`gh`) 계정을 그대로 쓴다.
끄려면 터미널에서 Ctrl+C. 처음에는 `gh auth login`으로 로그인되어 있어야 한다.

- **내 일**: 내가 맡은 일, 지금 먼저 할 일, 담당 없는 일(가져가기)
- **전체**: 할 일 / 진행 중 / 막힘 / 최근 2주 끝난 일. 사람으로 걸러 볼 수 있다
- **사람별**: 누가 무슨 일을 맡았고, 무엇을 끝냈고, 어떤 PR과 커밋을 올렸나
- **변경 기록**: main에 올라온 기능이 자동으로 쌓인다
- 줄에 마우스를 올리면 `시작 / 막힘 / 끝 / 내가 맡기 / 급함` 버튼이 나온다. 누르면 GitHub 이슈가 바로 바뀐다
- 오른쪽 위 `새 일`로 이슈를 만든다. 우선순위는 `급함`이 맨 위로 올라온다

웹 화면을 안 써도 아래 방법은 그대로 된다.

- 지금 상황: 이슈 탭 맨 위에 고정된 **📋 현황판**
- 무엇이 새로 생기고 바뀌었나: 고정된 **🆕 변경 기록** (main에 올라올 때마다 자동으로 쌓인다)

## 내가 할 일

1. 할 일이 생기면 `Issues` > `New issue` > `할 일`. 담당자(Assignees)를 정한다.
2. 시작하면 이슈에 `진행중` 라벨을 붙인다.
3. 막히면 `막힘` 라벨을 붙이고 댓글로 필요한 것을 쓴다.
4. 끝나면 PR을 올리고 본문 첫 줄에 `Closes #이슈번호`를 쓴다. 합치면 이슈가 닫히고 현황판의 "끝난 일"로 내려간다.

PR에 `Closes #번호`만 써도 현황판에 "진행 중"으로 올라온다. 현황판은 직접 고치지 않는다.

## 기록이 비지 않게

변경 기록은 파일 내용을 읽어서 만든다. 아래만 지키면 된다.

- 증강은 `resources/augments/*.tres`의 `display_name`과 `description`을 제대로 적는다.
- 새 `.gd` 파일은 맨 위에 `##`로 시작하는 한 줄 설명을 단다.

터미널에서 보고 싶으면: `python .github/team/team.py board` (GitHub CLI `gh` 로그인 필요)
