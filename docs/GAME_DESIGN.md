# 게임 및 증강 상태 흐름

## 매치 흐름

`MAIN_MENU → LOCAL_SETUP → INITIAL_AUGMENT_SELECTION(흑돌) → INITIAL_AUGMENT_SELECTION(백돌) → PLAYER_AIMING`

일반 발사는 `PIECES_MOVING → TURN_RESOLUTION`을 거친다. 액티브는 `PLAYER_AIMING → SKILL_TARGETING → PIECES_MOVING → TURN_RESOLUTION`이며 우클릭으로 선택을 취소할 수 있다. 즉시형 필드 스킬은 `SKILL_TARGETING` 없이 물리 해소로 이동한다. 네 번째 개인 완료 턴에는 `AUGMENT_SELECTION` 후 원래 예정된 상대 턴으로 복귀한다.

## 액티브 규칙

- 현재 플레이어가 소유하고 쿨다운·사용 횟수 조건을 만족하는 버튼만 활성화한다.
- 자기 돌, 상대 돌, 자기 돌 2개, 보드 위치 선택을 구분한다.
- 다단계 선택을 취소하면 임시 첫 대상도 초기화한다.
- 스킬은 기본적으로 발사 한 번과 같은 턴을 소비한다.
- 넉백이나 견인이 있으면 모든 돌이 멈춘 뒤 턴을 넘긴다.

## 물리 기본값

보드는 504×540px, 흑돌/백돌 반지름은 13.32/13.14px이다. 기본 최대 드래그는 120px, 드래그 1px당 충격량은 9.36, 최대 충격량은 1,123.2다. 반발 0.48, 마찰 0.24, 선형 감속 2.68, 기본 속도 상한 1,250px/s, 정지 기준 4px/s를 사용한다. 프로젝트와 돌의 중력은 모두 0이다.

발사력은 `min(드래그 거리 × 9.36, 최대 충격량 × 사거리 배율) × 음속 배율`로 계산한다. 조준경은 사거리와 최대 충격량을 1.3배, 음속 폭발은 최종 충격량과 속도 상한을 1.6배로 만든다. 두 증강 조합은 기본 대비 2.08배이며 적용 순서와 무관하다.
