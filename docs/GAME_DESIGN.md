# 게임 및 증강 상태 흐름

## 매치 흐름

`MAIN_MENU → LOCAL_SETUP → INITIAL_AUGMENT_SELECTION(흑돌) → INITIAL_AUGMENT_SELECTION(백돌) → PLAYER_AIMING`

일반 발사는 `PIECES_MOVING → TURN_RESOLUTION`을 거친다. 액티브는 `PLAYER_AIMING → SKILL_TARGETING → PIECES_MOVING → TURN_RESOLUTION`이며 우클릭으로 선택을 취소할 수 있다. 즉시형 필드 스킬은 `SKILL_TARGETING` 없이 물리 해소로 이동한다.

## 공동 라운드와 증강

- 흑돌과 백돌이 각각 정상 행동을 한 번 완료해야 공동 라운드가 1 증가한다.
- 행동 완료는 물리 정지, 탈락 및 승리 판정 뒤 호스트가 한 번만 확정한다. 승리한 경우 보상 선택을 열지 않는다.
- 게임 시작 전 첫 증강, 3라운드 완료 후 두 번째 증강, 6라운드 완료 후 세 번째 증강을 얻는다.
- 플레이어당 최대 보유량은 3개이며, 9라운드 이후에는 추가 선택이 없다.
- 로컬은 같은 선택 단계에서 흑돌과 백돌이 순서대로 고르고, 두 선택이 끝난 뒤에만 다음 라운드를 시작한다.
- 온라인은 양쪽 PC에 서로 독립적인 카드 3장을 동시에 표시한다. 먼저 고른 쪽은 상대 선택 완료를 기다린다.

## 조준 취소

조준 중 `Esc` 또는 마우스 오른쪽 버튼을 누르면 선택, 조준선과 파워 게이지를 즉시 초기화한다. 그 뒤 왼쪽 버튼을 놓아도 발사 요청을 만들지 않으며 턴과 라운드는 유지된다. 드래그가 8px 미만인 경우도 오발로 간주해 같은 방식으로 취소한다. 증강 선택이나 메뉴 화면에서는 이 조준 취소 처리를 실행하지 않는다.

## 액티브 규칙

- 현재 플레이어가 소유하고 쿨다운·사용 횟수 조건을 만족하는 버튼만 활성화한다.
- 자기 돌, 상대 돌, 자기 돌 2개, 보드 위치 선택을 구분한다.
- 다단계 선택을 취소하면 임시 첫 대상도 초기화한다.
- 스킬은 기본적으로 발사 한 번과 같은 턴을 소비한다.
- 넉백이나 견인이 있으면 모든 돌이 멈춘 뒤 턴을 넘긴다.

## 물리 기본값

보드는 504×540px, 흑돌/백돌 반지름은 13.32/13.14px이다. 기본 최대 드래그는 120px, 드래그 1px당 충격량은 9.36, 최대 충격량은 1,123.2다. 반발 0.48, 마찰 0.24, 선형 감속 2.68, 기본 속도 상한 1,250px/s, 정지 기준 4px/s를 사용한다. 프로젝트와 돌의 중력은 모두 0이다.

발사력은 `min(드래그 거리 × 9.36, 최대 충격량 × 사거리 배율) × 음속 배율`로 계산한다. 조준경은 사거리와 최대 충격량을 1.3배, 음속 폭발은 최종 충격량과 속도 상한을 1.6배로 만든다. 두 증강 조합은 기본 대비 2.08배이며 적용 순서와 무관하다.

월마리아 벽은 150×20px `StaticBody2D`와 같은 크기의 `RectangleShape2D`를 사용한다. 돌은 벽 레이어를 충돌 마스크에 포함하고 항상 CCD를 사용한다. 벽 반발력 0.88과 마찰 0.05는 설정 상수이며, 설치 전에 회전된 사각형과 모든 돌 사이의 실제 거리를 검사한다.
