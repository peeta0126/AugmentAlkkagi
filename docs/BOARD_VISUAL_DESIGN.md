# 바둑판·바둑알 시각 및 물리 규격

## 실물 환산

| 항목 | 최초 | 실물 비율 리디자인 | 현재 밸런스 |
|---|---:|---:|---:|
| 보드 | 560×560px | 504×540px | 504×540px |
| 흑돌 지름 | 50px | 26.64px | 26.64px |
| 백돌 지름 | 50px | 26.28px | 26.28px |
| 최대 기본 충격량 | 1,232.5 | 624 | 1,123.2 |
| 선형 감속 | 2.8 | 3.35 | 2.68 |
| 기본 최대 속도 | 1,250px/s | 900px/s | 1,250px/s |
| 음속 최대 속도 | 1,650px/s | 1,400px/s | 2,000px/s |

보드와 돌은 같은 월드 픽셀 환산을 사용한다. 화면을 채우기 위해 돌만 키우지 않는다. 보드는 1280×720 중앙에 물리 크기 그대로 표시되며 좌우 낙하 공간과 HUD 영역을 확보한다.

## 렌더링

외부 텍스처 없이 `_draw()`로 황갈색 판재 밴드, 서로 다른 두 주기의 나뭇결, 옹이, 상단 코팅 반사, 측면 두께와 그림자를 합성한다. 격자 영역은 보드 외곽과 분리되며 X/Y 여백은 실물 비율에 맞춘 25.2/27px이다. 19개 수직선과 19개 수평선, 인덱스 3·9·15의 화점 9개를 그린다.

돌은 소유자별 실제 반지름을 충돌체와 드로잉에 같이 사용한다. 눌린 접촉 그림자, 광원 방향으로 이동하는 11겹 동심 음영, 작은 반사광과 가장자리 반사를 조합해 렌즈형 곡면을 표현한다. 백돌에는 낮은 불투명도의 조개 결 두 줄을 추가한다.

## 물리 조정 이유

실물 비율 변경 때 적용했던 최대 충격량 624와 감속 3.35는 실제 플레이에서 지나치게 약했다. 현재는 충격량을 정확히 1.8배인 1,123.2로 높이고 감속을 80%인 2.68로 낮췄다. 최대 발사는 약 384px 이동하고 약 1.98초에 정지한다. CCD는 유지하며 외형·경계 제거·탱크 충돌체는 각 인스턴스의 `visual_radius`를 사용한다.
