# 테스트 보고서

검증 기준: Godot 4.7.2 Stable, Windows, Compatibility renderer, GodotPhysics2D.

## 2026-10-24 공동 라운드·증강 제한·벽·조준 취소 회귀 테스트

공식 Godot 4.7.2 Windows 바이너리로 다음 테스트를 다시 실행했고 모두 종료 코드 0과 PASS를 반환했다.

| 테스트 | 결과 | 추가 검증 범위 |
|---|---|---|
| `test_phase1.gd` | 통과 | 기본 규칙 회귀 |
| `test_game_scene.gd` | 통과 | Esc/우클릭 취소, 취소 뒤 왼쪽 버튼 해제, 8px 미만 드래그, 턴·라운드 미소비 |
| `test_board_geometry.gd` | 통과 | 보드와 돌 충돌체 회귀 |
| `test_augments.gd` | 통과 | 한쪽 행동만으로 라운드 미완료, 3·6라운드 양쪽 선택, 9라운드 추가 선택 없음, 최대 3개 및 네 번째 거절, 재시작 초기화 |
| `test_all_augments.gd` | 통과 | 20종 회귀, StaticBody2D/RectangleShape2D 벽, 충돌 레이어, 겹침 배치 거절, 음속 상한 고속 충돌, 지속 시간 제거, 벽 회전 직렬화 |
| `test_launch_balance.gd` | 통과 | 발사력·감속·돌 충돌 회귀 |
| 호스트/클라이언트 동시 하네스 | 통과 | 실제 ENet localhost, 양쪽 조준 취소, 공동 3라운드, 독립 카드 동시 선택/완료 배리어, 양쪽 2개 보유 동기화, 벽 위치·회전 동기화 |

초기 네트워크 재검증에서 벽이 포함된 스냅샷이 1,496바이트로 ENet MTU 경고를 냈다. 벽 상태를 `[id, x, y, rotation, turns]` 고정 `PackedFloat32Array`로 바꾼 뒤 같은 하네스를 다시 실행했고 MTU 경고 없이 양쪽 PASS를 확인했다.

자동화하지 못해 수동 확인이 필요한 항목:

- 실제 두 PC/Tailscale 환경에서 장시간 6라운드까지 플레이했을 때의 지연 체감
- 일반·탱크·음속·삼연발 돌이 월마리아에 부딪힐 때의 최종 반발력 체감 조정
- 창 모드에서 Esc가 조준 취소와 운영체제/추가 메뉴 단축키에 동시에 연결되지 않는지 확인
- 참가자 연결이 선택 도중 끊긴 뒤 로비 복귀 UI의 시각 확인

현재 작업 범위에서 재현되는 미해결 기능 버그는 없다. 헤드리스 샌드박스에서는 사용자 로그 경로 쓰기와 Windows 루트 인증서 읽기 경고가 출력됐지만 테스트 결과와 ENet localhost 통신에는 영향을 주지 않았다.

## 2026-10-23 자동 테스트

| `test_augments.gd` | 통과 | 선택 중복 방지, 소유 독립성, 탱크·음속·조준경과 중첩 |

localhost 통합 검사는 개발용 UDP 7787을 사용했고 두 Godot 프로세스를 동시에 실행했습니다. 최초 구현에서 3404바이트 스냅샷 MTU 경고가 발견되어 알 상태를 고정 배열로 압축했습니다. 수정 후 MTU 경고 없이 양쪽 프로세스가 종료 코드 0과 PASS를 반환했습니다.

물리 측정값:

- 이전 추정 최대 이동 거리: 186.27px
- 개선 추정 최대 이동 거리: 419.10px
- 실제 작은 발사 이동 거리: 94.98px
- 실제 최대 발사 이동 거리: 383.95px
- 최대 발사 정지 시간: 1.98초
- 충돌 대상 전달 속도: 121.69px/s

## 네트워크 검증 상태

자동 검증 완료:

- 서버 생성 및 클라이언트 접속
- 로비 준비와 3알 설정
- 호스트 RNG 기반 플레이어별 증강 제안/획득
- 호스트 권위 발사 및 클라이언트 발사 요청
- 현재 턴, 알 위치·속도·상태 스냅샷
- 클라이언트 물리 동결과 표시 보간
- 순차 턴 복귀
- 파싱 및 기존 로컬 기능 회귀

코드 경로 검증(수동 악성 패킷 주입 테스트는 미실시):

- 중복 sequence 거절
- 턴 외/소유권 불일치/없는 알/과도한 드래그 발사 거절
- 미보유·쿨다운 증강 및 잘못된 대상 거절
- 잘못된 IPv4와 포트 거절
- 정원 초과 연결 거절
- 호스트/참가자 연결 종료 처리

## 증강 네트워크 적용

20종 모두 획득 목록과 효과 런타임 상태가 동기화됩니다. 호스트가 모든 랜덤 결과와 실제 물리 결과를 결정합니다. 분열 알, 소유권 변경, 변신, 상태 효과, 필드, 임시 벽, 제거 및 특수 승리는 스냅샷에 반영되고 투사체 연출은 reliable RPC로 재생됩니다.

수동 시각 검증이 필요한 항목:

- 랜턴·눈덩이·화염구 연출의 실제 WAN 지연 체감
- 칙칙폭폭 예고선과 일부 순간 보드 선 이펙트의 클라이언트 표현(현재 결과 물리는 동기화되지만 일부 선 연출은 호스트 전용)
- 실명 강도의 각 PC별 접근성 체감
- 월마리아 + 칙칙폭폭 등 장시간 복합 조합의 WAN 스트레스

## 미검증/환경 제약

- 서로 다른 실제 PC 및 Tailscale 경로는 이 환경에서 실행하지 못했으므로 외부 연결 성공으로 보고하지 않습니다.
- Windows export 템플릿이 설치되어 있지 않아 실제 EXE 생성은 미검증입니다. `export_presets.cfg` 파싱과 프리셋은 준비했습니다.
- Godot 실행 로그 경로와 Windows 루트 인증서 접근 경고가 헤드리스 환경에서 출력되지만 테스트 및 ENet 결과에는 영향을 주지 않았습니다.
