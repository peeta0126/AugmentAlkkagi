# Augment Alkkagi 온라인 플레이 안내

## 실행 방법

1. ZIP 압축을 푼 뒤 `AugmentAlkkagi.exe`를 실행합니다.
2. 방장은 `온라인 방 만들기`를 누르고 화면의 6자리 방 코드를 친구에게 전달합니다.
3. 친구는 `온라인 방 코드 참가`를 누르고 받은 코드를 입력합니다.
4. 두 플레이어가 모두 `준비`를 켜면 방장이 `게임 시작`을 누릅니다.

별도 VPN, 포트포워딩, IP 주소 입력은 필요하지 않습니다. 두 PC 모두 인터넷 연결과 Windows 방화벽의 앱 네트워크 접근 허용이 필요합니다.

## 역할과 연결 종료

- 방장은 흑돌, 참가자는 백돌입니다.
- 방장이 나가거나 GD-Sync 연결이 끊기면 현재 온라인 대전은 종료됩니다.
- 온라인 연결에 문제가 있으면 메인 메뉴의 `LAN / Tailscale`에서 기존 UDP 직접 연결 방식을 사용할 수 있습니다.

## 배포 및 보안 참고

- GD-Sync API 키는 GD-Sync 1.0.2 공식 export 플러그인을 통해 내장 PCK에 추가됩니다.
- 원본 `addons/GD-Sync/keys.cfg`는 Git과 배포 ZIP에 별도 파일로 포함되지 않습니다.
- 배포용 GD-Sync 키를 별도로 사용하고, 실행 파일이 의도하지 않은 곳에 공개된 경우 대시보드에서 키를 교체하세요.
