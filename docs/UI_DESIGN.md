# UI 디자인

기본 해상도는 1280×720, `canvas_items` + `expand`를 사용한다. 중앙에는 504×540px 세로형 보드를 배치하고 좌우 330px 이내에 HUD를 둔다. 플레이어는 색상만이 아니라 `흑돌`·`백돌` 텍스트, 금색/아이보리 강조, 선택 외곽선으로 구분한다.

버튼은 기본/호버/누름/비활성 스타일을 별도로 가진다. 구현 전 기능은 비활성화하고 Phase 표기를 붙여 오해를 막는다. 게임 HUD는 중앙에 현재 턴과 생존 수, 좌측에 파워와 안내, 우측에 메뉴를 배치해 보드 조작 영역을 침범하지 않는다.

설정 화면의 전체 화면 전환과 마스터 음량 슬라이더는 즉시 실제 엔진 설정에 반영된다. 영구 저장은 후속 작업이다.

증강 선택은 중앙에 카드 3장을 배치하며 이름·설명·등급 테두리·문자 아이콘·호버 확대를 제공한다. 실명은 보드 영역만 덮어 메뉴와 시스템 HUD 조작을 유지한다. 화면 흔들림/고대비/실명 강도는 후속 접근성 설정 대상이다.

## 액티브 스킬

현재 플레이어의 사용 가능한 액티브/필드 증강은 보드 오른쪽 아래에 버튼으로 표시한다. 버튼에는 이름과 남은 횟수 또는 쿨다운을 함께 표시한다. 버튼을 누르면 `SKILL_TARGETING` 상태가 되어 기본 발사를 차단하고, 좌측 하단 안내문이 필요한 대상 순서를 설명한다. 우클릭은 다단계 선택까지 초기화하며 취소한다.
